# 🚀 VEXOP – Digital Marketing Agency Website

Die Website entstand im Auftrag für eine frisch gegründete Marketingagentur aus London. Das moderne Design stammt aus einer Figma-Vorlage und wurde von mir Anfang 2024 mit Vue.js umgesetzt.
Der Erstkontakt entstand über Instagram – die Zusammenarbeit verlief vollständig remote.
<br>
<br>

## 🌐 Projektüberblick
Die Website vermittelt Professionalität und Kreativität – zwei Kernwerte der Agentur. Neben dem stilvollen Layout wurde besonderer Wert auf eine responsive Darstellung und flüssige User Experience gelegt.
